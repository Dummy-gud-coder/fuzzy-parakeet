This document verifies that the client-side Mermaid component correctly intercepts and renders `language-mermaid` code blocks.

## 1. Flowchart (System Architecture)

```mermaid
graph TD
    A[MDX Source] --> B[MDXRemote Parser]
    B --> C{Is language-mermaid?}
    C -- Yes --> D[Client-Side Mermaid Component]
    C -- No --> E[Shiki Syntax Highlighting]
    D --> F[SVG Rendered in Browser]
    E --> G[Standard Pre/Code Block]
```
```mermaid
sequenceDiagram
    autonumber
    actor User
    participant Browser
    participant NextJS

    User->>Browser: Navigate to Page
    Browser->>NextJS: Request HTML
    NextJS-->>Browser: Return Static HTML & JS Bundle
    Browser->>Browser: Hydrate React Components
    Browser->>Browser: Execute Mermaid.run()
    Browser-->>User: Display Rendered SVG Diagram
```

    Rendered --> [*]
